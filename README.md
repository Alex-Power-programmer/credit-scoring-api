# Credit Scoring API (Machine Learning Microservice)

Промышленный микросервис для оценки кредитных рисков и предсказания вероятности дефолта заемщика. 

## 🚀 Стек технологий
* **ML**: Python 3.9, LightGBM (Recall: 0.84, Precision: 0.61), Scikit-Learn, Joblib
* **Backend**: FastAPI, Pydantic v2, Uvicorn
* **Database & Logging**: PostgreSQL, Psycopg2, RotatingFileHandler
* **DevOps**: Docker, Docker Compose

---

## 🛠 Пошаговый запуск проекта

Проект полностью контейнеризирован. Вам не нужно устанавливать Python, PostgreSQL или библиотеки машинного обучения локально. Всё поднимется автоматически.

### 1. Клонирование репозитория
Откройте терминал и скачайте проект на свой компьютер:
```bash
git clone https://github.com
cd credit-scoring-api
```

### 2. Запуск инфраструктуры через Docker Compose
Убедитесь, что у вас запущен Docker Desktop, и выполните команду:
```bash
docker-compose up -d --build
```
*Эта команда автоматически скачает образ PostgreSQL, соберет образ FastAPI, установит системные C++ зависимости (libgomp) для LightGBM и свяжет контейнеры по внутренней сети.*

### 3. Первоначальная инициализация базы данных
Поскольку база данных поднимается абсолютно чистой, запустите скрипт для автоматического создания таблиц и заливки исторических данных из CSV:
```bash
python init_db.py
```

## 🖥 Использование и проверка

После успешного запуска API будет доступно по адресу: **`http://127.0.0.1:8000`**

* **Интерактивная документация (Swagger UI)**: Перейдите на [http://127.0.0](http://127.0.0), чтобы протестировать эндпоинты.
* **Одиночное предсказание (`POST /predict`)**: Принимает анкету клиента и возвращает вероятность дефолта, категорию риска (`Низкий`, `Критический` и т.д.) и рекомендацию банка. Результат автоматически логируется в БД.
* **Пакетное предсказание (`POST /predict_batch`)**: Оптимизированная массовая обработка списка клиентов за один запрос через `execute_values`.

## 📁 Структура проекта
* `app/main.py` — маршруты FastAPI и логика обработки запросов.
* `app/model.py` — инициализация ML-модели (паттерн Singleton) и предобработка данных.
* `app/utils.py` — функции бизнес-логики и интеграции с PostgreSQL.
* `app/schemas.py` — строгая валидация входящих и исходящих данных на Pydantic v2.
* `train_model.py` — скрипт обучения градиентного бустинга LightGBM с тюнингом порога классификации.
